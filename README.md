# 拾光集市——校园二手交易平台

## 一、项目简介

拾光集市面向高校学生，帮助同学低成本买卖教材、数码产品和生活用品。平台提供商品展示、关键词搜索、分类筛选和闲置发布功能，减少闲置浪费，促进校园资源循环利用。

## 二、技术方案

- 前端：HTML5、CSS3、Jinja2 模板
- 后端：Python Flask
- 数据库：SQLite
- 开发工具：PyCharm

## 三、运行方法

在 PyCharm 打开本文件夹，在 Terminal 中执行：

```bash
pip install -r requirements.txt
python app.py
```

浏览器访问 `http://127.0.0.1:5000`。

## 四、创新点

1. 场景聚焦校园，交易双方有共同学校身份，沟通和当面交易更方便。
2. 通过分类、搜索降低信息查找成本。
3. 让闲置物品在校内循环，减少浪费，符合绿色校园理念。
4. 后续可增加信用评价、校园认证、在线聊天和智能推荐。

## 五、汇报稿（约 1 分钟）

大家好，我们的项目是“拾光集市——校园二手交易平台”。调查发现，大学生毕业或搬宿舍时会产生大量教材、数码产品和生活用品闲置，但传统交易群信息分散、搜索困难、信任感不足。因此，我们设计了一个面向本校学生的二手交易网页。用户可以浏览商品、按分类筛选、搜索关键词，也可以发布自己的闲置物品。项目采用 Python Flask 和 SQLite 开发，成本低、容易部署，适合作为校园数字化服务。未来我们计划加入校园身份认证、信用评分和智能推荐，打造更安全、更高效的校园闲置共享平台。
